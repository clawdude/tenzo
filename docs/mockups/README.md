# Mock-ups

Source frames from the design session (2026-10-02). The live, clickable canvas is at
https://claude.ai/artifact/4MhJY4g6QnyL4CxHggJqKi (private; ask for access).

Files are Design-canvas components (`.dc.html`). The static ones open in a browser as plain HTML.
`Pass.dc.html` is the interactive pile and needs the canvas runtime to play.

- `Pass.dc.html` — the chosen direction: the pile, suggested answer + free text, snooze, all clear
- `B1` why it's asking · `B3` the change · `B2` what happened so far (backs of the card)
- `C2` snooze toast · `D1` all clear
- `A1`–`A4` — the four question-card variations compared before choosing A1
- `Threads`, `NewThread` — round 2, not yet redone in the pile language
